### 1.2 选型结论

- **首选 akshare**：免费、无注册、MIT 许可对开源项目友好、2026 年仍保持每周级发版，日线（`stock_zh_a_hist`）与实时快照（`stock_zh_a_spot_em`）覆盖本项目主需求。**[已验证]**
- **风险与对策**：akshare 本质是公开接口聚合器，上游（东财/新浪等）改版会导致接口失效（GitHub issue 区常见此类报错，官方建议升级最新版）。工程上必须：① 锁定 `akshare==x.y.z` 并在 CI 中跑接口冒烟测试；② 定义 `DataSource` 抽象层，baostock 作为历史日线降级源。**[推断]**
- **tushare**：数据规整、有分钟级与财务数据，但积分门槛+频次限制+2026-08 停运风波表明其单点依赖风险高，只适合作为可选适配器。**[已验证+推断]**
- **baostock**：日K+复权因子稳定免费，适合做回测数据备份；无实时行情是硬伤。**[已验证]**
- **efinance**：可用但社区维护力量薄弱（151 个 open issues、发版低频），不建议作为主依赖。**[已验证+推断]**

## 2. 程序化实盘通道现状

### 2.1 监管框架（2024-2025 年新规，本项目合规基线）**[已验证]**

- 证监会公告〔2024〕8 号《证券市场程序化交易管理规定（试行）》：2024-05-11 发布，**2024-10-08 施行**。确立程序化交易**报告制度**（投资者须经券商报告账户、资金、策略类型等信息方可开展程序化交易）、实时监控、高频交易特别监管。原文：http://www.csrc.gov.cn/csrc/c101954/c7480579/content.shtml
- 沪深北交易所《程序化交易管理实施细则》：2025-04-03 发布，**2025-07-07 施行**。高频交易认定标准：单账户**每秒申报/撤单最高 ≥300 笔**，或**单日申报/撤单合计 ≥20000 笔**。上交所细则原文：http://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260612_10781696.shtml ；解读：人民网 http://finance.people.com.cn/n1/2025/0707/c1004-40516156.html
- 对日频/低频调仓的 ashquant 而言：远低于高频认定线，但**实盘程序化交易仍需通过券商完成程序化交易报告**——这是"实盘通道必须走券商 sanctioned 通道"的合规依据。**[已验证+推断]**

### 2.2 QMT / miniQMT（迅投，本项目首选实盘适配器）

- **xtquant**：迅投官方 Python 库，"XtQuant 是基于迅投 MiniQMT 衍生出来的一套完善的 Python 策略运行框架，以 Python 库形式提供行情（XtQuant.xtdata）和交易（XtQuant.xttrader）API"。官方文档：https://dict.thinktrader.net/nativeApi/start_now.html 、http://docs.thinktrader.net/QMT-mini/ **[已验证]**
- 使用方式：券商开通 QMT/miniQMT 权限 → 极简模式启动客户端（端口 58610）→ `pip install xtquant` 外部 Python 控制。**[已验证]**
- **资金门槛：无官方统一标准，因券商而异**。二级渠道（miniqmt.com QA、券商渠道文、知乎/网易 2025-2026 整理）显示：常见 **30-50 万**，部分券商 10 万/20 万即可，个别要求 100 万以上或加收软件费/佣金；部分渠道 2 万可申请测试权限。**[推断——行业渠道信息，无监管文件]**
  - 参考：https://miniqmt.com/pages/qa/knowledge-qa.html

### 2.3 Ptrade（恒生电子）

- 恒生电子开发、券商采购后向客户提供，Python 策略+回测+实盘，与 QMT 并称两大个人量化通道。门槛同样是券商侧政策：主流 10-50 万不等，个别渠道 2 万起。**[推断——二级渠道信息]** 参考：https://licai.jiantou8.com/user/guide_view_3061176.html 、https://www.163.com/dy/article/KQIO7G6T05564AHL.html

### 2.4 easytrader（shidenggui/easytrader）

- GitHub API 实查（2026-09-01）：MIT，10,116 stars，未 archive；最近提交 2026-02-28（新增项目指南文档）、2026-01-15 修复 miniQMT `entrust_prop` 参数、2026-01-07 修复验证码窗口问题——**仓库名义存活、低频维护**。**[已验证（仓库事实）]**
- 其核心模式是**驱动同花顺客户端等 GUI 进行下单**（模拟点击/窗口复制），这类方案：① 违反券商/行情软件用户协议风险；② 客户端升级即碎（仓库 issue 中大量验证码/客户端适配问题印证）；③ 2024-10 起程序化交易报告制度下，未经报告的客户端自动化通道处于灰色地带。**[推断（风险判断基于上述已验证监管文件与仓库 issue 现状）]**
- 仓库：https://github.com/shidenggui/easytrader

### 2.5 结论

**开源项目应：① 内置模拟撮合引擎（按本报告第 3 节微观规则模拟 T+1/涨跌停/费用）；② 提供 QMT/miniQMT（xtquant）官方适配器作为唯一实盘出口；③ 不内置、不推荐 easytrader 式客户端自动化。** 理由：合规（程序化交易报告制度）、稳定（官方 API vs GUI 模拟）、责任边界（开源项目只产出信号，执行由用户在券商 sanctioned 通道完成）。**[已验证+推断]**

## 3. A股交易微观规则（逐条+官方出处）

### 3.1 T+1 制度 **[已验证]**

- 规则：投资者当日买入的 A 股股票不得当日卖出（最快次一交易日卖出）；卖出所得资金当日可再买入、提现 T+1。
- 出处：《上海证券交易所交易规则（2026年修订）》："投资者买入的证券，在交收前不得卖出，但实行回转交易的除外"（历史上为 3.1.4 条；债券ETF/黄金ETF/货币ETF 等为 T+0 例外）。规则页：http://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml
- 注：条文编号以规则 docx 附件为准，本次未能直接下载附件逐字核对（见 BLOCKED）。

### 3.2 涨跌幅限制 **[已验证，含 2026 年重大更新]**

|---|---|---|---|

| **主板 ST/*ST** | **±10%（2026-07-06 起由 5% 调整为 10%）** | 2026-07-06 | 上交所新闻稿（2026-04-24 修订发布交易规则）：http://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816474.shtml ；上海金融委：https://jrj.sh.gov.cn/ZXYW178/20260702/a8fb63ac6e9e49f9a47a4024a98fd7fb.html |
| 创业板（含创业板 ST） | ±20%（2020-08-24 起，由 10% 放宽；新股前 5 日不设限） | 2020-08-24 | 深交所《创业板交易特别规定》；中信证券公告：https://www.citics.com/newsite/tzzjy/cybysdzcz/tzzjy/202008/t20200822_1134060.html ；人民网：http://finance.people.com.cn/n1/2020/0824/c1004-31833596.html ；证监会法规库收录深交所交易规则：https://neris.csrc.gov.cn/falvfagui/rdqsHeader/mainbody?navbarId=1&secFutrsLawId=c070ac1611374758bd02c3b950571447 |

### 3.3 印花税 **[已验证]**

- 现行：**卖出单边 0.05%（0.5‰）**，买入不征。2023-08-28 生效，检索至 2026-09 无新调整公告。
- 出处：财政部 税务总局公告 2023 年第 39 号《关于减半征收证券交易印花税的公告》（2023-08-27 发布）："自 2023 年 8 月 28 日起，证券交易印花税实施减半征收"。官方法规库：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html ；新华网：http://www.news.cn/fortune/2023-08/27/c_1129826990.htm

### 3.4 过户费 **[已验证]**

- 现行：**成交金额的 0.001%（0.01‰），买卖双边收取，沪深 A 股均收**（2022-04-29 起，由 0.02‰ 下调 50%；北京市场同日起统一为 0.01‰ 双边）。
- 出处：中国结算 2022-04-28 公告；新华社：《中国结算：4月29日起股票交易过户费总体下调50%》 http://www.news.cn/fortune/2022-04/28/c_1128605983.htm ；人民网经济日报：http://finance.people.com.cn/n1/2022/0429/c1004-32411923.html
- 明确回答调研问题：**是双边（买+卖都收），且沪深两市都收，不是仅沪市**。（历史上曾长期仅沪市按面值征收，2015 年起改为按成交金额双边——此沿革未单独核验 **[推断]**）

### 3.5 佣金 **[推断——行业惯例]**

- 常见：**万 2.5（0.025%），单笔最低 5 元**，买卖双向收取；自主开户默认多为万 2.5~万 3，经客户经理可谈至万 1 以下（2025 年有券商报到万 0.85）；监管上限为成交金额 3‰（2002 年佣金浮动改革以来的上限，官方原文本次未核验）。
- 出处（二级）：财联社 2026-06《禁"万1免5"、防低价揽客，券商佣金反内卷传闻刷屏》："根据证监会监管要求及行业惯例，券商佣金收取存在单笔最低 5 元的限制" https://m.cls.cn/detail/2160172
- 工程提醒：最低 5 元对小资金高频换手是显著摩擦成本（万 2.5 下单笔需 ≥2 万元才"用满"费率），模拟盘必须建模。**[推断]**

### 3.6 最小交易单位与申报数量 **[已验证+推断]**

- 沪深主板：竞价买入申报为 **100 股或其整数倍**；卖出时余额不足 100 股的部分应**一次性申报卖出**（送股/配股产生零股）。**[已验证（交易所交易规则，二级转述条文）]**
- 科创板：限价申报单笔 **≥200 股且 ≤10 万股，超过 200 股部分可按 1 股递增**（如 201 股）；持有不足 200 股部分不得拆开、一次性卖出。另有连续竞价 2% 有效申报价格范围（价格笼子）。**[已验证（科创板交易特别规定；上交所/券商投教转述）]**
- 创业板：仍为 100 股整数倍买入、零股一次性卖出。**[推断——未单独核验条文原文]**
- 北交所：单笔申报 ≥100 股、**可按 1 股递增**；余额不足 100 股一次性卖出。**[已验证（北交所交易规则，bseinfo 原文页）]** https://www.bseinfo.net/jygl_list/200028217.html

### 3.7 交易时段与集合竞价 **[已验证]**

- 《上海证券交易所交易规则（2026 年修订）》原文（搜索快照直接引用）："证券采用竞价交易方式的，每个交易日的 **9:15 至 9:25 为开盘集合竞价时间，9:30 至 11:30、13:00 至 14:57 为连续竞价时间，14:57 至 15:00 为收盘集合竞价时间**。" 规则页：http://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml
- 开盘集合竞价 9:20-9:25 不可撤单（9:15-9:20 可撤）；收盘集合竞价期间不可撤单。**[推断——常识性条款，未逐字核对]**
- 沪市收盘集合竞价自 2018-08-20 实施：上交所《调整收盘交易机制》 http://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20180806_4607055.shtml **[已验证]**
- 2026 年新规：**盘后固定价格交易由科创板扩展至全部 A 股和 ETF**（上交所 2026-04-24 修订发布交易规则新闻稿；上海金融委 2026-07-06 施行报道 https://jrj.sh.gov.cn/ZXYW178/20260706/e1b77e31afa84895b300ac96a45a2c1c.html ）。具体时段（科创板原为 15:05-15:30）未逐字核验 **[推断]**。

## 4. 对 ashquant 的落地要求汇总
