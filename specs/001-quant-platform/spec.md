# Feature Specification: ashquant 量化交易平台 MVP

**Feature Branch**: `001-quant-platform`

**Created**: 2026-09-01

**Status**: Approved for Planning

**Input**: User description: "做一个类似量化的A股交易平台：实时交易股票、查看涨跌、预测明天走势；回测过去三年A股行情；结合巴菲特等高手言论；自测两天后开源发布。"（原始诉求中『回测预测成功率99%+』经 `specs/research/03-prediction-feasibility.md` 论证为不可实现目标，按宪法第 I 原则转译为诚实指标体系，见 Assumptions A1。）

## Clarifications

### Session 2026-09-01（自治模式：用户不在线，以下决策均附依据，可被用户复核推翻）

- Q: 默认回测股票池用什么规模？ → A: 默认 20 只样本池（演示/测试可快速全链路跑通），同时提供"沪深300 全量"显式命令；依据 SC-001 与 A7。
- Q: 策略信号如何映射为仓位？ → A: 等权 Top-K 持仓，默认 K=5、每 5 个交易日调仓、单票权重上限 20%，全部可配置；依据 freqtrade/backtrader 主流实践，防单票集中风险。
- Q: Web 实时快照如何刷新？ → A: 自动轮询，默认 5 秒（可配），CLI 另提供单次快照与监听两种模式；依据免费快照源频率与防限流。
- Q: "预测命中率"的唯一口径是什么？ → A: T 日收盘后发布预测，目标为 T+1 收盘价相对 T 收盘价的涨跌（close-to-close），预测日志与统计 MUST 固定此口径；依据可审计性与最常见的次日涨跌定义。
- Q: 本地缓存用什么存储格式？ → A: 留给 plan 阶段定（倾向列式 parquet，理由：列式读取快、带类型、pandas 原生支持）；规格层只约束"本地文件级、可复现、含元数据"。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 看盘：实时查看自选股涨跌 (Priority: P1)

个人投资者打开本地 Web 页面或运行 CLI 命令，输入自选股代码（如 600519、300750），
看到每只股票的现价、涨跌幅、涨跌额，以及最近三年的日 K 线图。

**Why this priority**: "查看股票的涨跌情况"是用户的核心诉求第一条，也是其他一切
功能（预测/回测/交易）的数据与界面基础。

**Independent Test**: 启动 Web 页面（或 CLI 单次快照命令），输入代码后 10 秒内
展示实时快照与 K 线；断网时给出明确错误提示而非崩溃。

**Acceptance Scenarios**:

1. **Given** 交易时段内本地已缓存日线，**When** 用户查询自选股快照，**Then** 返回
   代码/名称/现价/涨跌幅/涨跌额/更新时间，且数据时延在分钟级以内。
2. **Given** 非交易时段，**When** 用户查询快照，**Then** 返回最近一个交易日收盘快照
   并明确标注数据时点。
3. **Given** 用户在 Web 界面选择某股票，**When** 查看 K 线，**Then** 展示带成交量、
   均线、可缩放的日 K 图（近三年）。

---

### User Story 2 - 回测：三年 A股规则保真回测 (Priority: P1)

用户选定股票池与策略（大师信号合成策略），对过去三年（默认 2023-09-01 至今）做
回测，得到：累计收益、年化、最大回撤、夏普、逐日预测日志，以及沪深300 买入持有
基准对照与「零成本 vs 真实成本」敏感性对比。

**Why this priority**: 用户核心诉求第二条；也是验证策略与系统诚实性的唯一途径。

**Independent Test**: 命令行一次运行完成回测并输出报告文件；同一缓存数据上重跑两次
结果逐分逐毫一致（可复现性）。

**Acceptance Scenarios**:

1. **Given** 本地已缓存三年日线，**When** 运行回测，**Then** 输出含收益/回撤/夏普/
   胜率的报告，并强制附带沪深300基准对照。
2. **Given** 某股票当日涨停（开盘即涨停价），**When** 策略想买入，**Then** 回测判定
   无法成交（涨停不可买），收益不得计入。
3. **Given** 当日 T+0 想卖出今仓，**When** 交易引擎收到卖单，**Then** 拒绝（T+1）。
4. **Given** 同一数据缓存，**When** 重跑回测，**Then** 权益曲线完全一致。

---

### User Story 3 - 预测：明日走势预测与大师观点 (Priority: P2)

用户对任一已缓存股票发起预测，系统输出：明日方向（看涨/看跌/观望）、上涨概率、
置信度，以及各投资大师信号代理的独立观点（打分 + 理由 + 名言出处，如巴菲特、
格雷厄姆、利弗莫尔、索罗斯、芒格）。所有历史预测落盘为可审计日志，可统计真实
命中率、覆盖率与校准度。

**Why this priority**: "预测明天走势+结合高手言论"是用户核心诉求第三条；置于 P2 是
因为依赖 P1 的数据层。

**Independent Test**: 对已缓存股票运行预测命令，输出结构化结果（方向/概率/置信度/
大师观点清单）；对预测日志运行统计命令，输出命中率与覆盖率。

**Acceptance Scenarios**:

1. **Given** 股票已有 ≥120 个交易日缓存，**When** 发起预测，**Then** 输出方向、上涨
   概率、置信度与至少 4 位大师代理的独立观点（含名言原文出处）。
2. **Given** 概率接近 50%（无把握），**When** 输出预测，**Then** 方向为"观望"
   （弃权机制），并说明弃权原因。
3. **Given** 已积累 N 条已到期的预测记录，**When** 运行命中率统计，**Then** 输出
   命中率、覆盖率、按置信度分层的校准表。
4. **Given** 回测产生的逐日预测日志，**When** 审计其中任意一天，**Then** 该日信号
   只使用了该日及之前的数据（无未来函数）。

---

### User Story 4 - 交易：模拟盘下单与持仓管理 (Priority: P2)

用户在模拟盘（默认形态）以虚拟资金买入/卖出股票，系统按 A股规则撮合（T+1、
涨跌停、整手、佣金/印花税/过户费），随时查看持仓、浮动盈亏与账户净值曲线；
并提供可选的 QMT（miniQMT/xtquant）实盘适配器接口，用户自配后可实盘下单。

**Why this priority**: "实时交易"是用户核心诉求第四条；安全默认原则要求默认模拟盘，
实盘通道做成显式配置的可选适配器。

**Independent Test**: 模拟盘命令完成买入→持仓查询→次日卖出（T+1 拦截当日卖出）→
对账单导出的完整闭环。

**Acceptance Scenarios**:

1. **Given** 模拟账户有现金，**When** 买入 100 股某股票，**Then** 按成交价扣除价款+
   佣金（最低 5 元）+过户费，持仓记录买入日期。
2. **Given** 当日买入的股票，**When** 同日再发卖单，**Then** 拒绝并提示 T+1。
3. **Given** 实盘适配器未配置，**When** 尝试实盘下单，**Then** 明确提示需要用户自行
   配置 QMT，不产生任何订单。
4. **Given** 用户导出对账单，**Then** 每笔成交含时间/价格/数量/费用明细，买卖差额
   与账户流水勾稽一致。

---

### User Story 5 - 开源发布就绪 (Priority: P3)

项目以 MIT 协议开源：中文 README（功能/安装/快速开始/免责声明/诚实性声明）、
LICENSE、贡献说明；仓库内无任何私人凭据；一键本地安装与测试。

**Why this priority**: 用户计划自测两天后开源发布；发布就绪是验收前置条件而非
功能本体，故 P3。

**Independent Test**: 全新目录克隆/解压后按 README 三条命令内完成安装+测试+启动。

**Acceptance Scenarios**:

1. **Given** 全新环境（有 Python 3.12+），**When** 按 README 安装，**Then** 依赖解析
   成功且测试全部通过。
2. **Given** 仓库做密钥扫描，**Then** 无 token/账号/密码命中。

---

### Edge Cases

- 数据源接口失败/限流：重试 + 明确报错（含接口名与建议），不写半截数据（原子写缓存）。
- 停牌/长期停牌股票：K 线缺口保留，回测跳过无行情日，不给停牌日发信号。
- 新股上市不足 120 个交易日：预测功能明确提示数据不足，不输出结果（不硬造信号）。
- ST/退市整理股票：涨跌停阈值按规则切换（主板 ST：2026-07-06 前 5%、后 10%）。
- 代码格式容错：`600519`、`sh600519`、`600519.SH` 均可识别为同一标的。
- 缓存与上游冲突：以前复权数据重抓时整段替换，不与旧数据拼接（防复权口径错位）。
- 极端行情（连续一字涨停/跌停多日）：买/卖持续无法成交，回测如实呈现滞留风险。

## Requirements *(mandatory)*

### Functional Requirements

**数据层**
- **FR-001**: 系统 MUST 能从免费公开数据源抓取 A股日线（开高低收量额，前复权）与
  全市场实时快照，并落地本地缓存（含来源与抓取时间元数据）。
- **FR-002**: 系统 MUST 支持按股票池（默认 20 只样本池、可选沪深300成分、自定义列表）
  批量抓取近三年日线，且中断后可续抓（已完成的股票不重抓）。
- **FR-003**: 所有对外行情接口 MUST 屏蔽上游字段/接口名差异（适配器层），上游不可用
  时 MUST 给出可操作的错误信息。

**指标与信号**
- **FR-004**: 系统 MUST 提供常用技术指标计算（MA/EMA/MACD/RSI/BOLL/ATR/ROC/
  量比/波动率），且仅使用计算时点及之前的数据。
- **FR-005**: 系统 MUST 实现 ≥4 个可独立测试的"大师信号代理"（至少覆盖：趋势跟踪、
  均值回归、风险控制、情绪逆向四类哲学），每个代理输出 [-1,1] 打分、理由文本与
  名言出处（引用 `specs/research/04-master-quotes.md` 中已核验语录）。
- **FR-006**: 系统 MUST 将多代理信号合成为综合分并校准为上涨概率；概率与 50% 之差
  小于阈值时 MUST 输出"观望"。

**回测**
- **FR-007**: 回测引擎 MUST 强制执行 A股微观规则：T+1、按板块与日期判定涨跌停
  （主板10%/创业板与科创板20%/北交所30%/主板ST 5%→10% 以 2026-07-06 分界）、
  涨停不成交买单、跌停不成交卖单、100 股整手、佣金（默认万 2.5 最低 5 元，可配）、
  印花税卖出 0.05%、过户费双边 0.001%。
- **FR-008**: 回测 MUST 产出逐日预测日志（预测日、标的、方向、概率、实际次日涨跌、
  是否命中），作为一切"预测成功率"声明的唯一数据来源。
- **FR-009**: 回测报告 MUST 附带沪深300 买入持有基准对照与零成本/真实成本敏感性。
- **FR-010**: 同一缓存数据上重跑回测 MUST 得到逐日一致的权益曲线（确定性）。

**预测**
- **FR-011**: 实时预测 MUST 输出：方向（看涨/看跌/观望）、上涨概率、置信度、大师
  代理观点清单；数据不足（<120 交易日）MUST 拒绝并说明。
- **FR-012**: 每条实时预测 MUST 追加写入预测日志（含特征快照摘要），到期后自动与
  实际行情对账（口径：T+1 收盘对 T 收盘的 close-to-close 涨跌），支持输出命中率/
  覆盖率/校准度统计。

**交易**
- **FR-013**: 模拟盘 MUST 支持：初始虚拟资金设置、买入/卖出、持仓与浮动盈亏查询、
  交易记录与账户净值导出；撮合规则与 FR-007 完全一致（同一规则引擎）。
- **FR-014**: 实盘 MUST 仅通过用户显式配置的券商适配器（QMT/miniQMT·xtquant）启用；
  适配器缺失时系统 MUST 完整可用除实盘外的一切功能。
- **FR-015**: 系统 MUST NOT 内置任何券商客户端 GUI 自动化；凭据 MUST NOT 出现在
  仓库、日志与默认配置中。

**界面与发布**
- **FR-016**: Web 界面 MUST 提供：自选股实时快照表（自动刷新）、单标的日 K 线
  （含均线与成交量）、发起预测并展示大师观点。
- **FR-017**: CLI MUST 提供：数据抓取、回测、预测、快照、模拟盘、Web 启动命令，
  且支持 JSON 输出模式（供脚本与测试消费）。
- **FR-018**: 项目 MUST 以 MIT 发布，README 含中文快速开始与「不构成投资建议」
  及诚实性声明（链接可行性报告）。
- **FR-019**: 回测策略 MUST 支持等权 Top-K 仓位模型（默认 K=5）、调仓间隔
  （默认 5 个交易日）与单票权重上限（默认 20%）三项参数配置。

### Key Entities

- **Bar（日线）**: 标的代码、日期、开高低收、成交量额；属于某标的的时间序列。
- **SpotQuote（实时快照）**: 标的、现价、涨跌幅、涨跌额、快照时间。
- **MasterSignal（大师信号）**: 代理名、哲学类别、打分、理由、名言出处、计算时点。
- **Prediction（预测）**: 标的、预测日、目标日、方向、上涨概率、置信度、构成信号、
  到期后补记的实际结果与命中标志。
- **Order/Fill（订单/成交）**: 方向、标的、数量、请求价、成交价、费用明细、状态
  （含因涨跌停未成交）。
- **Position（持仓）**: 标的、可卖数量（T+1 约束）、成本、买入日期。
- **Portfolio（组合/账户）**: 现金、持仓集合、净值曲线、交易记录。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对 20 只样本股完成三年日线抓取与缓存，全程无人工干预，可断点续抓。
- **SC-002**: 三年回测一次运行内完成，且同一缓存重跑两次权益曲线 100% 一致。
- **SC-003**: 回测报告同时呈现策略与沪深300基准的收益/回撤/夏普，以及成本敏感性
  对比（用户可直接看到成本对收益的侵蚀）。
- **SC-004**: 回测逐日预测日志可审计：随机抽查任一日，其信号输入均不晚于该日收盘。
- **SC-005**: 对任一缓存 ≥120 交易日的股票，预测在 5 秒内返回结构化结果
  （方向/概率/置信度/≥4 个大师观点）。
- **SC-006**: 模拟盘完整闭环（入金→买→T+1 拦截→次日卖→对账）在测试中 100% 正确
  执行 A股规则（T+1、涨跌停、费用）。
- **SC-007**: Web 页面在本地浏览器 10 秒内呈现自选股快照与 K 线，快照自动刷新。
- **SC-008**: 新环境按 README ≤3 条命令完成安装并通过全部测试；密钥扫描零命中。
- **SC-009**: 所有对外文档与界面文案不出现任何"保证收益/99% 胜率"类表述，
  预测界面固定展示免责声明。

## Assumptions

- **A1（核心转译）**: 原始诉求「回测预测成功率 99%+」不可实现（证据链见
  `specs/research/03-prediction-feasibility.md`：学术 SOTA 月度 R²≈0.4%、顶级基金
  日胜率≈50.75%、99% 胜率 9.3 年吸干 A股总市值的数学归谬）。本规格将其转译为
  诚实指标体系：方向命中率（预期带 52-58%）+ 覆盖率 + 校准度，全部由可审计
  预测日志支撑。这是宪法第 I 原则的强制要求。
- **A2**: "实时行情"指免费公开源的快照级（秒~分钟级延迟）数据，非交易所 Level-1/2
  逐笔授权行情（后者需付费牌照，超出开源个人项目范围）。
- **A3**: 单用户本地工具形态，不做多用户/鉴权/云部署；数据库为本地文件级存储。
- **A4**: 实盘以 QMT/miniQMT（xtquant）为唯一适配目标，且用户需自行满足券商开通
  条件（资金门槛等）；默认与 CI 环境均不依赖它。
- **A5**: 日线（bar 级）粒度为主，tick 级高频不在范围（宪法合规条款）。
- **A6**: 主数据源 akshare（MIT、活跃维护、无门槛），baostock 作为历史日线备份源
  （见 `specs/research/02-ashare-data-and-brokers.md`）。
- **A7**: 股票池默认提供"沪深300成分"与"自选列表"两种；不承诺全市场 5000+ 只
  一次性回测的性能（可运行但耗时较长）。
